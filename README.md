## ✨ Features

- Dark mode glassmorphism design with gradient accents
- Fully responsive — mobile (375px), tablet (768px), desktop (1280px)
- Parallax scrolling effect on Hero section background blobs
- 5+ on-scroll animations using Framer Motion with useInView
- Accessibility — prefers-reduced-motion media query included
- SEO optimized — meta tags, Open Graph, semantic HTML

### Sections
1. Hero — Name, role, animated blobs, parallax, CTAs
2. About — Bio, SVG avatar, stats, skill highlights
3. Skills — Tech stack grid with icons, certifications
4. Projects — QLUE, CREATOROS, PLANZO with GitHub links
5. Contact — Email, GitHub, LinkedIn, phone, contact form
6. Footer — Copyright, social links

## 🚀 Getting Started (Local Development)

### Prerequisites
- Node.js 18+ (download from https://nodejs.org)
- npm 9+

### Installation and Running

```bash
# 1. Clone the repository
git clone https://github.com/nikhitadasari26/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

The site will be available at http://localhost:5173

### Build for Production

```bash
npm run build
```

The optimized build will be in the dist/ folder.

### Preview Production Build

```bash
npm run preview
```
